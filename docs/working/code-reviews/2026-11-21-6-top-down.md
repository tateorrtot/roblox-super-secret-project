## A guideline for folders
```

-script1
-script2
- \ inventory
- - script1
- - script 2
```
> Items is allowed to depend on inventory and the scripts below. Inventory cant rely on the scripts above it. Maybe thats not a great way to do it - idk. I just want to try and avoid climing up directories for things. Dont get too hooked on that one example im not sure if youd apply it there or not.
