## A guideline for folders
```
\ items
-script1
-script2
- \ inventory
- - script1
- - script 2
```
> Items is allowed to depend on inventory and the scripts below. Inventory cant rely on the scripts above it. Maybe thats not a great way to do it - idk. I just want to try and avoid climing up directories for things. Dont get too hooked on that one example im not sure if youd apply it there or not. This comes from "signal up - call down" philosphy of godot.

- **Measured:** of the 85 requires in `src/shared`, 67 climb out of their folder with `../`. Of its 28 files, 6 never climb. 11 files climb to `ItemStack`, 5 to `Position`, 4 to `ItemRegistry`, and 2 to `Signal`.
- **A script can check the rule:** no require holds `..`.
- **What the rule asks of every folder:** a thing that two folders both use is handed to each by the folder above them, or is a library that is required by its name, as an addon's class is in Godot.
