What Claude takes from the third review (Claude's reading):
- **The user reads an outline of names, with no arguments and no comments, and expects to know what each function does.** That is the test a name must pass.
- **A bare verb is only for the whole thing.** `Timer.start` starts the timer. A function that acts on a part of the thing, or on something handed to it, names that part and the place: `pickUpFromSlot`, not `pickUp`.
- **A noun in a name is read as something passed in.** "moveStack" promises that a stack is passed.
- **Claude had written itself an exemption** ("verbs from the game are used where they are plainer"), and the names the user could not read were the exempted ones. It is removed.

Claude had been showing readers the types and the comments and asking what a call returns, which passed every name the user could not read.
