# The status block that was in the map until 2026-11-21

Three bullets of `CLAUDE.md`, moved here word for word on 2026-11-21, when a cold reader found that the map held a daily status against its own rule. They say how the code got its shape over the user's reviews, what was next that day, and what waited on the user. What is next now is in `docs/status/next.md`.

- **The code** was rewritten on 2026-11-20 over nine reviews by the user, on three branches each cut from the one before: `first-pieces`, `dropped-items`, `placed-objects`. After the tenth, each item and each kind of placed object got a script of its own, the game's things moved to `src/shared/content`, and the clicks on the world moved to Roblox's input actions. After the twelfth and the thirteenth, an item is one table, a crate and a stove each carry what they are made of, and the word `station` is gone. After the fourteenth, each kind of placed object makes its own Model, and `python tools/reference.py` writes a class reference from the comments. After the fifteenth, no thing has a colour, and every comment was rewritten to `docs/code/comments.md`, which `tools/check` now enforces. After the sixteenth and seventeenth, a page of the reference draws code as code and links its types, four modules have an example that runs, and `moveFromSlotToInventory` is taken apart into `Inventory.takeFromSlot` and `Inventory.addStack`, with the request as the glue. After the eighteenth, no function of the rules takes a `side`: only a request does. No branch is merged. Nothing is pushed.
- **Next:** first, the game is broken down from the top, and the top is the user's: items and moving them around; objects that are placed or broken; entities, parked (`docs/status/next.md`). Never list systems from the code that exists. Each leaf that works in any game is a library in a folder beside this one, built by a session that is told nothing of the game. `inventory` and `ground-items` were built, reviewed, and mended on the night of 2026-11-21, and `gyms/items` joins them into the first loop with about 95 lines of glue. This repo's `src` moves onto the libraries only after the user has read them. After that: every other comment is written as three pages now are: each noun an argument, a field, a type, or a value, and each argument said to be what it is (`docs/code/comments.md`). The user said yes to that, and likes the code pattern of single jobs joined by glue. The pages of the reference are still hard to read cold (`docs/status/now.md`). Then how an item looks, with stand-in art of Claude's own. Then a plot as placed objects that hold together on one body, which they confirmed on 2026-11-21: building and physics are two systems, joined by glue (`docs/status/next.md`). Then the keys onto input actions, then prediction on the client, which they approved.
