## Does isolating a library make the result better?
You asked: "If I sandboxed you into different repos will you perform better?" The night's evidence:
- **For.** Neither library has a word of the game in it. Both designs differ from what I wrote with the game in view, and answer your reviews: an inventory is a bare list of slots, a slot carries its own rule, a held stack is a plain variable, and no type has room for exactly two of anything. A helper with no knowledge of the code built three unrelated things from each page alone and opened no source file. The gym joined both libraries with glue that never reaches inside either.
- **Against, or not shown.** Each library passed every check and every mutation run of its own while it held real faults: a recipe on a page that lost items, a merge that missed drops lying at the same place, and saved data that could not be read back. A reviewer's probes found them, not the sessions that wrote them. So isolation removed the game's contracts, and did not remove the need for review. Also: the briefs carried the lessons of your twenty reviews; you have read none of this yet; and nothing has run inside Roblox.
